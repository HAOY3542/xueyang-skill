# XUEYANG SKILL

> 给地产营销同行的汇报方法：先讲清手里有什么，每页用一句话给结论，数据有对比、经得起复算，动作写清谁、何时做完，需要支持就直接提。

这套方法提炼自地产营销负责人包雪洋 2023–2026 年的多份实战汇报，类型包括专项汇报、定价方案、车位专项、招商专项、年度复盘、季度汇报、周报、年度启动会和经验分享。

它是一个 Agent Skill（SKILL.md 格式）。装进 Claude、Codex 等 AI 工具后，可以按这套方法起草、修改、排版和预审地产营销汇报。

## 适合谁

地产营销岗位的同行都可以用：

- 营销负责人、项目营销经理、城市 / 区域营销管理
- 销售经理、案场主管、置业顾问
- 渠道、拓客、分销、自获客
- 策划、品牌、推广、新媒体
- 销管、销控、营销运营
- 客研、定价
- 非住、商业招商、车位

## 能做什么

| 任务 | 说明 |
|---|---|
| 起草 / 梳理 | 按要求交付大纲、文案或文件；资料足够时直接完成，只有缺少会改变方向的信息或你要求先确认时才提问 |
| 改稿 | 先列问题清单，再在你允许的范围内修改，好的原句和数据保留 |
| 只改排版 | 文字、数字、日期、页序逐字不动，只调版面 |
| 预审 | 用领导的眼光过一遍：哪页会被追问、哪些必须改、缺哪些数据或依据 |

## 核心方法

1. **开头先摆实底**：账面总量 → 受限部分（先去重）→ 当期可用 → 对目标的缺口。
2. **每页一句话总结**：每个内容页都有一句给出结论的话；数量、比例、变化类判断带数字和口径，定性判断有具体依据。全篇的标题和一句话总结连起来读，就是一份能直接念的提纲。
3. **先找对比对象，再下结论**：同时间窗、同产品、同状态、同单位，没有参照的数字不下结论。
4. **先验证，再提方案**：竞品、租金、客群、现场证据先摆出来；需要拍板的方案要比较。
5. **算账要让人能复算**：写清方法、权重、公式和口径，不套用历史参数。
6. **动作和结果一起说**：过程量和结果量分开写，没结果就直说。
7. **排进时间表**：日期｜核心动作｜量化目标｜责任人。
8. **需要支持就说清楚**：每条写清卡点、影响、要的决定或资源、找谁、什么时候；没有就不写。

格式规则都是默认做法，不是硬模板；起草或允许改内容时，每个内容页必备一句话总结。用户指定的修改范围、页数和母版优先，只改排版时不新增总结或改写内容。

完整内容见 [SKILL.md](SKILL.md)，包括常用汇报骨架、页型库、语言习惯、数据口径纪律、边界和预审清单。

## 安装

下载发布包 [xueyang-skill-v2.5.zip](https://github.com/HAOY3542/xueyang-skill/releases/download/v2.5/xueyang-skill-v2.5.zip)，里面已经是 `xueyang-skill` 文件夹，可以直接使用。分享给同事时，直接把这个 ZIP 发过去就行。下面的解压命令需在 ZIP 所在文件夹运行；已有同名技能时，先备份旧文件夹再替换。

### Claude（网页 / 桌面）

1. 打开 **Customize > Skills**，点 **+** → **Create skill** → **Upload a skill**，直接上传这个 ZIP。
2. 需要先开启代码执行（Settings > Capabilities）。
3. Team / Enterprise 版还可以在技能里点 **Share** 分享给同事，前提是管理员开启了分享功能。

### Claude Code

```bash
mkdir -p ~/.claude/skills
unzip xueyang-skill-v2.5.zip -d ~/.claude/skills/
```

装好后的路径是 `~/.claude/skills/xueyang-skill/SKILL.md`。只想在某个项目里用，就解压到该项目的 `.claude/skills/`。

### Codex

```bash
mkdir -p ~/.agents/skills
unzip xueyang-skill-v2.5.zip -d ~/.agents/skills/
```

对话里输入 `$xueyang-skill` 调用。项目级用法是解压到仓库的 `.agents/skills/`。`agents/openai.yaml` 提供显示名称和默认提示。

### 其他工具

支持 Agent Skills（SKILL.md）格式的工具，按各自的文档放进技能目录即可。不支持的工具，可以把 SKILL.md 的全文当作提示词或项目说明使用。为了方便这种用法，整套方法只写在 SKILL.md 一个文件里。

### 从 GitHub 安装

也可以直接克隆本仓库：

```bash
# Claude Code
git clone https://github.com/HAOY3542/xueyang-skill ~/.claude/skills/xueyang-skill
# Codex
git clone https://github.com/HAOY3542/xueyang-skill ~/.agents/skills/xueyang-skill
```

在 GitHub 网页上点 **Download ZIP** 下载时，解压出的文件夹名通常带分支名（例如 `xueyang-skill-main`）。上传到 Claude 前，先确认技能文件夹名为 `xueyang-skill`，并以该文件夹为根目录重新压缩。

- 用 XUEYANG SKILL 改这份销售周报。我是销售经理，重点讲复访、认购和未成交抗性，保持 5 页。

- 用 XUEYANG SKILL 搭一份商铺定价方案的框架，列出还缺哪些测算输入。
- 用 XUEYANG SKILL 只调这份 PPT 的排版，文字一个字都不要动。
- 用 XUEYANG SKILL 预审这份季度汇报：领导会在哪几页追问？哪些必须改？

## 来源与说明

- 方法提炼自包雪洋本人于 2023–2026 年制作的多份实战汇报。仓库只保留方法本身，不含原稿、项目数据、客户信息和公司模板。文中的示例数据都是虚构的。
- 这里写的是能从原稿中观察到的写法，不代表作者的全部思考。用了它，也不能保证每份汇报都被认可。
- 不规定字体、配色和模板，套用你公司的母版即可。
